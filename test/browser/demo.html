Right-click each image below

Served over HTTP so the extension can read the bytes. Default settings assumed (WebP only, byte sniffing on).

1. A WebP at a .webp address

Expect: Save WebP as JPG and Save WebP as PNG. Saving gives a 960×856 file.

2. The same WebP at a .jpg address, served as image/jpeg

Expect: still Save WebP as JPG / PNG — both the name and the header are lying, and only the bytes give it away. This is the case a filename-based extension gets wrong.

3. A real PNG

Expect: no menu items by default. Turn on Show the menu for every image in Preferences and they appear as Save Image as JPG / PNG.

4. A WebP with transparency

Expect the menu, and Save WebP as JPG should fill the transparent area with the colour set in Preferences (white by default, not black). Save WebP as PNG keeps it transparent.

5. A link to a WebP (no image involved)

Expect the menu on the link itself.

lossy-960x856.webp

6. A WebP behind a blob: URL

Expect the menu, and a successful save — the background page cannot read this URL, so the extension asks the page for the bytes instead.
